# 改造方案对照

本文件在步长和主题改造阶段记录。以下“初步方案”由 Codex 在编写前提出，不冒充学生本人事前猜测；本次没有使用 TraeWork。

| 项目 | 初步方案 | 对照后采用的方案 | 原因 |
| --- | --- | --- | --- |
| 步长 | 直接把 ++ 改为 += 2 | State 保存 _step，弹层提供 1/2/5，_count += _step | 满足可调节步长并保留累计值 |
| 主题 | 将示例主题改为 teal | ColorScheme.fromSeed 加 Theme.of 取色 | 统一 AppBar、文字、FAB 的视觉风格 |
| 状态 | 在页面中保存计数和步长 | 两者均置于 CounterPage 的 State | 每次 build 不重新初始化 |
| 资源 | 直接调用 Image.asset | 同步声明 pubspec 路径，完整启动验证 | 防止资源未打包 |

验证由 Codex 执行静态分析、组件测试与浏览器检查；学生本人需复核代码并完成口头讲解。
