## 四 关键代码与设计

Student 用 _score 封装分数，所有构造入口执行 setter 校验。fromJson 使用 `(json['score'] as num).toDouble()` 兼容整数与浮点分数。

排名组合 `where → toList → sort → map → toList → asMap → map`，依次筛选、复制、排序、映射并生成从 1 开始的名次，排序不改动原列表。四项基础统计也均使用集合方法，无手写 for 循环。

改造前：`class GradeBookBefore extends LoggingBase`。

改造后：`class GradeBook with Logger`。

日志属于独立能力，成绩册与日志器没有业务继承关系。混入移除了仅为日志复用增加的继承层。example/mixin_refactor.dart 提供可运行前后对照。

## 六 问题与调试

实际遇到 Dart 遥测配置访问被拒绝，以及沙箱禁止 Dart 写入 pubspec.lock 的环境问题。将 APPDATA 和 PUB_CACHE 指向临时目录，并通过获准执行完成配置和校验，未修改用户 SDK。

空值处理：空成绩册没有最高分学生，maxBy 因而声明为 Student?，先判断空列表再调用 reduce；读取其分数时应使用 `book.maxBy?.score`。空册测试验证返回 null。JSON 使用 num 转 double 兼容整数。这里是已验证的设计处理，不声称发生过未实际出现的类型错误。
